# BankMonitor

Навчальна система моніторингу роботи СУБД на прикладі банківських переказів. Генератор створює навантаження на PostgreSQL через чергу RabbitMQ, Prometheus збирає метрики, Loki — логи, Tempo — трейси, Grafana все показує, а доступ до системи можливий лише після входу через власний сервер авторизації. Усе запускається в Docker однією командою.

Опис системи, архітектура й план робіт — у [`docs/00-common.md`](docs/00-common.md). Повна інструкція з запуску з'явиться тут на завершальному етапі.
